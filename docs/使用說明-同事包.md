# 排班助手 — 使用說明

歡迎！這個資料夾讓你用 **AI 助手**協助排班。你只需要**對話**和**你的 Excel**，
不需要懂程式。

## 資料夾裡有什麼

| 項目 | 用途 |
|---|---|
| `docs/` | 說明文件（規則、如何填 Excel、常用更改說法） |
| `config/rules.json` | 排班規則設定（由 AI 助手代你修改，你不需要打開） |
| `scripts/schedule.py` | 產生排班結果 Excel（填好的時間表） |
| `scripts/verify.py` | 跑數指令（只報排到／排不到的數字） |
| `api/` | 排班引擎（不要改動） |
| `data/輸入/` | **把你的 Excel 放這裡**；內有一個 `demo_start.xlsx` 可先試 |
| `data/輸出/` | 排班結果會自動存到這裡 |
| `AGENT指引.md` | 給 AI 助手看的操作守則 |

## 第一次設定（只需做一次）

1. 安裝 **Python**（3.10 或以上）：https://www.python.org/downloads/
   安裝時記得勾選「Add Python to PATH」。
2. 開啟這個資料夾的終端機（PowerShell），安裝需要的套件：
   ```
   pip install -r requirements.txt
   ```
3. 準備 **work buddy**（你們使用的 AI 助手），在這個資料夾開啟。

## 日常怎樣用

1. 把你的 Excel 放進 `data/輸入/` 資料夾（排班結果會出現在 `data/輸出/`）。
2. 對 AI 助手說出你想做的事，例如：
   - 「把 DAE102 的 TS1、TS2 合併去 TM4」
   - 「老師一星期最多教 8 班」
   - 「幫我看看有多少班排不到，最緊張的中心是哪個」
3. AI 助手會：改設定或 Excel → 跑數 → **告訴你排到多少、排不到多少、有沒有超額**。
4. 你覺得合適 → AI 助手會**自動記錄**這次更改；不滿意 → 叫它還原。

## 交回給負責人

當你完成一段工作，對 AI 助手說「**打包給負責人**」，
它會產生一個 `.bundle` 檔，你用電郵／雲端／USB 傳給負責人即可。
負責人會檢視你的更改，把好的合併到正式版本。**你不需要用 GitHub。**

## 幾個提醒

- **你只改設定和 Excel 資料**；排班的「演算法」是負責人設計的，AI 助手不會改。
- **每次更改都會有數據和記錄**，如果 AI 只說「改好了」而不給數字，叫它跑數給你看。
- 想了解規則背景，看 `docs/排班規則與排法-完整版.md`；
  想知道怎樣填 Excel，看 `docs/如何填Excel.md`；
  想知道常用的更改說法，看 `docs/排班規則-同事版.md`。

## 先試一次（用示範檔）

對 AI 助手說：
> 「用 data/輸入/demo_start.xlsx 跑一次，告訴我排到多少、排不到多少。」

預期它會回報：排到 102、排不到 24、超額 0（結果檔在 data/輸出/）。這代表環境設定成功。
