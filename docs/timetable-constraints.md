### Cadet（學警）班特別規則（S3 相關）

- Cadet 班 ＝ 學警班，**有其指定課室**，**固定於星期三、五上課**
- 因有指定課室，**會影響其他原本已排好的班**（需相應調整）

### 合班分組決定（Jo 確認，2026-08）

天水圍（TS）課室不足的處理：

- **TS 數學班（DAE103_TS1–4）→ 留在 TS 上課**
- **TS 英文班（DAE102）→ 在 TM 上課**：
  - `DAE102_TS1 ＋ DAE102_TS2` → 併入 `DAE102_TM4`
  - `DAE102_TS3 ＋ DAE102_TS4` → 併入 `DAE102_TM5`
- **實作方式（重要）：** TS 學生已計入 TM4／TM5 的人數，故 `DAE102_TS1–4` 為**多餘的空 placeholder（0 人）**，直接從 Class list 移除即可。移除後 TS 課室騰空，TS 數學班可全部排回 TS。
- 註：系統的 CC Combine 機制在此情況排不到（cohort 的 Core 已排滿，L1 找不到跨校區日子），故採用「移除多餘 placeholder」而非合班機制。

## 🟢 英文科／Net 教師規則（已由 Jo 確認）

| 項目 | 內容 |
|---|------|
| Net 教師 | 由 Jo 指定，在「Net Teachers」名單中標記（不限人數） |
| Net 要求 | 每個非豁免班每學期 **≥1 個 Net block**（＝20 Net 小時） |
| 豁免班 | CS1、CS2、CS3、CS7 |
| 交通 | 英文教師同日跨校區上限 **30 分鐘** |

| 分配方式 | 系統可自動分配；若 Jo 想手動指定個別班，於「English Weekly」表填寫即覆寫自動結果 |
