# 示範 Prompt（貼給 work buddy 用）

在**排班助手資料夾**內開啟 work buddy，然後複製下面的 prompt 貼上。

---

## Prompt 1 — 跑一次排班並產生結果檔

> 使用前：把你的 Excel 放進 `data/輸入/` 資料夾，並把下面的 `<你的檔名>` 換成實際檔名。
> 想先試，可直接用內附的 `data/輸入/demo_start.xlsx`。

```
你是我們的排班助手。這個資料夾是排班系統的工具包。請用中文，照以下步驟做：

1. 先閱讀 `使用說明.md` 和 `docs/AGENT指引.md`，用一兩句話告訴我你的角色，以及你可以改什麼、不可以改什麼。

2. 我已經把我的 Excel 放進 data/輸入/ 資料夾。請跑完整排班並產生結果檔，執行：
   python scripts/schedule.py "data/輸入/<你的檔名>.xlsx"
   結果檔會存到 data/輸出/ 資料夾，排好的時間表在「Class Assignments」分頁。

3. 再執行以下指令，給我排到／排不到的詳細數字：
   python scripts/verify.py "data/輸入/<你的檔名>.xlsx"

4. 清楚報告：排到多少、排不到多少、有沒有超額（應為 0）、哪些中心最緊張，以及結果檔在 data/輸出/ 的位置。

5. 如果幾乎全部排不到，很可能是「Class list answer」分頁有殘留資料（要留空系統才會自動排）。請檢查並提醒我。

6. 最後用一句話總結：系統是否成功自動排班，並告訴我去哪裡看排好的時間表。
```

**兩個指令的分別：**
- `schedule.py` → **產生填好的排班結果 Excel**（時間表在「Class Assignments」分頁）。
- `verify.py` → 只報數字（排到／排不到／各中心），不產生檔案。

**注意 1：** 排好的結果在**另一個輸出檔**的「Class Assignments」分頁，**不是**寫回你輸入檔的「Class list answer」（輸入檔那頁要保持留空，系統才會自動排）。
**注意 2：** 「課室不足」不能靠放寬老師上限解決——課室數量不夠是硬性限制，只能靠合併細班、分流或接受。

---

## Prompt 2 — 規則導覽（讓用家先明白，再提出更改）

```
請你做我的排班系統導覽員。目標：用我聽得明的方式，把這個系統的規則和排法解釋一次，讓我明白背景，之後才提出更改。

請先閱讀這兩份文件：
- docs/排班規則與排法-完整版.md（全部規則 + 系統如何排班）
- docs/排班規則-同事版.md（我可以更改什麼、怎樣向你表達）

然後用中文、分段、用日常說話（不要技術術語）向我解釋：

1.【系統做什麼】一句話：輸入 Excel，自動排出每班的日、時、室、老師。

2.【怎樣排】系統排班的次序（先排 Cadet 班 → 核心班 → 合併班 → 派老師），以及「揀課室」的原則（先本組房，坐不下就揀啱大細的房）。

3.【硬性規則】一定遵守的（例如：課室要坐得下、老師不能同時教兩班、TKO 要 10 點後、學生同日只在一個中心…）——逐條用一句白話講。

4.【軟性規則】盡量遵守、必要時放寬並提醒的（例如：老師一週建議 6 班可超過只提醒、同科分散不同日、避免天地堂…）。

5.【我可以改什麼】列出我可以請你調整的東西（上課日、老師上限、合併分組、課室容量寬容度…），每項附一句「我可以怎樣跟你說」的例子。

6.【重要提醒】哪些情況不是靠改規則能解決的（例如某中心課室數量不足，屬硬性限制）。

每一部分保持簡短。解釋完，問我有沒有想先了解或想調整的地方。
```

---

## 建議次序

先用 **Prompt 2**（規則導覽）讓用家理解背景 → 再用 **Prompt 1**（跑排班）看實際結果 → 之後用家就可以用日常說話請 work buddy 調整（見 `docs/排班規則-同事版.md`）。
