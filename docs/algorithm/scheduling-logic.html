時間表排班系統

「你只需告訴系統，哪位老師哪天唔得閒——其餘交給系統。」

系統是什麼

一句話解釋

你提供班別名單、老師資料、課室名單，
系統自動幫你填好整份時間表——哪天、幾點、哪個課室、哪位老師。

以前要人手把 100+ 班填入時間表，既費時又容易出錯（例如同一位老師被排了兩個同時進行的班）。這個系統把這件事自動化。

你要提供什麼

只需填一份 Excel

整份 Excel 有幾個分頁，每個分頁填一類資料：

  • 📋
    班別名單 必填 所有班別的代號（例如 DAE101_TW2）、科目、每週課時、學生人數
  • 👩‍🏫
    老師名單 必填 每位老師可教哪些科目，以及最多可以教幾班（Quota）
  • 🏫
    課室名單 必填 每個課室的代號及座位數，系統用來配對合適大小的課室
  • 🗓️
    老師不可用時間 可選 哪位老師哪天哪個時段唔得閒，填 N，空白即任何時間均可

系統輸出給你：

  • 每個班別排在哪天、幾點、哪個課室
  • 每個班別的主教老師（Lec1）及後備老師（Lec2、Lec3）
  • 完整的每日時間表（Mon 至 Fri）
  • 可直接下載的 Excel 檔
排班過程

系統怎樣排？用 4 個步驟

  • 1

    讀取所有資料

    系統把 Excel 裡的班別、老師、課室全部讀進記憶體，準備開始計算。

  • 2

    為每個班別找一個「時間 + 課室」

    系統逐個班別（由人數多到少）嘗試找一個合適的時間和課室安排。 找到了就記下來，找不到就留待人手補排。

  • 3

    為每個班別找一位老師

    時間和課室確定後，系統再找一位合適的主教老師，然後再找兩位後備。 規則很簡單：教得、唔衝突、唔超出本身可教的班數上限。

  • 4

    輸出 Excel 供下載

    把所有排班結果整理成 Excel，顯示在網頁時間表上，可以直接下載。

課室怎麼選

課室跟班別代號掛勾

🏫

原則：同一個分組，永遠用同一個課室

班別代號已經包含了課室資訊。例如 DAE101_TW2， 「TW2」代表屯門分校第2號課室，即 TW - TW2。 所以同一組的所有科目（中文、英文、數學…）都用同一個課室，學生唔使四處走。

1️⃣

第一選擇：直接用代號對應的課室

DAE101_TW2 → 用 TW - TW2

2️⃣

如果對應課室已被其他班佔用

找同一個分校（TW 中心）最大的空置課室，確保座位夠用

3️⃣

如果整個分校都滿了

全校範圍找一個座位夠用的空置課室（比較少見）

時間怎麼選

先 Monday，然後輪流分配

系統優先把班排在受歡迎的日子，次序如下：

① Mon → ② Tue → ③ Thu → ④ Wed → ⑤ Fri
🃏

問題：如果所有數學班都搶 Monday 呢？

假設數學有 28 班，全部都想排 Monday——但 Monday 只有 6 位數學老師， 最多同時教 6 班。如果 28 班全塞進 Monday，老師根本不夠用。

解決方法：「輪流發牌」

就像發撲克牌一樣，每班數學輪流從不同的日子開始嘗試，確保平均分佈到每一天：

班別
優先嘗試的日子
DAE103_TW1（第1班）
Mon 優先 → 排到 Monday
DAE103_TW2（第2班）
Tue 優先 → 排到 Tuesday
DAE103_KT1（第3班）
Thu 優先 → 排到 Thursday
DAE103_CS1（第4班）
Wed 優先 → 排到 Wednesday
DAE103_ST1（第5班）
Fri 優先 → 排到 Friday
DAE103_TM1（第6班）
Mon 優先 → 輪回 Monday（另一個時段）
結果：28 班數學平均分佈到 5 天，每天約 5-6 班，老師輕鬆搞掂。

每班的課時是 4 小時（一個上午或一個下午）：

🌅

上午 block

0900–1100 + 1100–1300（連續兩節）

🌇

下午 block

1400–1600 + 1600–1800（連續兩節）

老師怎麼分配

三個條件都符合才分配

✅

條件 1：教得這科

老師在「Teacher load table」裡有登記這個科目，且未超出自己的班數上限（Quota）

🚫

條件 2：沒有衝突

那個時間段，這位老師沒有在教其他班——同一時間不能身兼兩職

📅

條件 3：那天有空

老師在「Teacher Availability」表格中沒有標記 N（不可用）

👩‍🏫👨‍🏫👩‍🏫

找到了？太好了。找不到？

主教老師（Lec1）找不到時，系統會放寬「班數上限」再找一次。 如果真的沒有人——例如所有數學老師那個時段都有課——才會標記為「未能分配老師」， 提醒管理員人手處理。

每個班找到主教後，系統再找兩位後備（Lec2、Lec3），後備只需不衝突即可。

排不到怎麼辦

系統會告訴你哪些班需要人手處理

⚠️

未能分配老師

班別已有時間和課室，但所有合資格老師在那個時段都有課。

解決方法：在網頁時間表拖移這個班到另一時段，或在 Teacher load table 增加老師。

❌

找不到課室

沒有找到座位足夠的課室。

解決方法：在 Centre Room Allocation 補充課室資料，或減少學生人數（換課室）。
