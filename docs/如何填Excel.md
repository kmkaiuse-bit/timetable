# 如何填寫排班 Excel

> 這份文件教你把資料填入 Excel，讓系統自動排班。
> 建議由 **V4 範本**（介面「下載 V4 Template」）開始，各分頁已備好。

---

## 最重要一點

**「Class list answer」分頁要完全留空。**
留空，系統才會**自動排班**（自動填入日／時／室／老師）。
若這頁有資料，系統會當成「已排好」而照用，不會自動排。

---

## 各分頁怎樣填

### 1. Class list（班別清單）— 必填

每一行一個班。欄位：

| 欄位 | 填什麼 | 例子 |
|---|---|---|
| Subject Code | 班代碼，格式 **科目_組別** | `DAE101_TW2` |
| Subject Name (English/Chinese) | 科目名稱 | `Chinese Language` / `中文` |
| Lecturer 1 / 2 / 3 | **留空**（系統會自動編配老師）；只在想指定時才填 | |
| Loading | 每週上課時數：**4**＝4 小時（排一個上午或下午）、**2**＝2 小時 | `4` |
| Student No | 學生人數（**要準確，決定用多大課室**） | `30` |
| Venue / Time / Date (optional) | **留空**（自動排）；只在想鎖定某班時才填 | |
| CC Group | 要合併上課的班填**相同標籤**；不合併留空 | `CC-DAE106-1` |

**班代碼格式：** `科目_組別`。組別代碼＝**中心＋組號**，例如
`TW2`＝屯門第 2 組、`CS1`＝長沙灣第 1 組、`TS3`＝沙田第 3 組。

**Cadet 班**（制服團隊）：組別用**單一英文字母**（例 `DAE256_E`），系統會自動當作 Cadet，排星期一、三、五。

### 2. Teacher load table with subject（老師可教科目）— 必填

- 每個老師的姓名，以及**每一科可教的班數（quota）**。
- 系統據此決定「誰可以教哪一科」。老師姓名前的稱謂（Mr./Ms.）可有可無。

### 3. Centre Room Allocation（課室）— 必填

- 每間課室的**代碼**與**座位數**。
- 系統據此分配課室；**不會**把班排入坐不下的課室。

### 4. Teacher Availability（老師不可用時間）— 選填

- 老師**不可用**的時間格填 `N`；其餘**留空**（＝任何時間都可以）。

### 5. Net Teachers（英文 Net 老師）— 選填（英文科用）

- 列出 Net 老師姓名。系統確保每個非豁免英文班每學期至少 1 個 Net 時段。

### 6. English Weekly（英文每週安排）— 選填

- **留空** ＝ 系統自動分配英文老師；只在想手動鎖定個別班時才填。

### 7. Class list answer（排班結果）— **留空！**

- V4 自動排班時**完全留空**，系統會自動填入結果。

---

## 合併班（CC Group）怎樣填

1. 在 Class list 的 **CC Group** 欄，要合併的班填**相同標籤**（例 `CC-DAE102-1`）。
2. 規則：
   - 必須**同科**（相同 Subject Code 前綴，如都是 DAE102）；
   - 合併後**總人數要坐得下一間課室**（只合併小班）；
   - 例：`DAE102_TS1`＋`DAE102_TS2`＋`DAE102_TM4` 都填 `CC-DAE102-1` → 三班一起在同一室上。

---

## 填好之後

1. 儲存 Excel。
2. 上載到排班系統（或交給 AI 助手）。
3. 系統排完會顯示：排到多少、排不到多少（及原因）、老師上課量。
4. 不滿意可修改資料再上載。

---

## 常見錯誤

| 錯誤 | 後果 | 正確做法 |
|---|---|---|
| Class list answer 有殘留資料 | 系統不自動排,只照抄 | **清空**這一頁 |
| Student No 填錯或留空（0） | 課室大小算錯、可能排錯 | 填**準確**人數 |
| CC Group 兩班標籤不完全相同 | 不會合併 | **一字不差**填相同標籤 |
| 合併的班不同科 | 系統拒絕合併（H5） | 只合併**同科**的班 |
| 合併後人數超過任何課室 | 排不到 | 只合併**小班** |
| 班代碼格式不對（缺底線／組別） | 認不出中心／Cadet | 用 `科目_組別`（Cadet 用單字母組別） |
